# Milestone 4 closure checklist

**Pending user acceptance. No `v0.4.0` tag or public deployment exists.**

## Review gates

- [ ] Accept 4.3 after reviewing its [report](milestone-4-3-portfolio.md),
  runbooks, synthetic tours, captures, exports and evidence inventory.
- [ ] Confirm final branch commit and successful quality CI, including real
  PostGIS migrations, OSRM/VROOM smoke and both portfolio tours.
- [ ] Preserve 4.2 residual advisories, local single-user scope, workload caps
  and historical benchmark/runtime boundaries.
- [ ] Review paired backup/restore, scoped reset safeguards and executed Windows /
  Linux CI versus reviewed user WSL instructions.
- [ ] Review source license, dependency notices and OSM attribution; metadata
  inventory does not certify redistribution compliance.
- [ ] Record blocked cleanup exactly; do not retry the 4.1 rejection.

## Only after explicit closure authorization

- [ ] Fetch/review remote main, preserve legitimate advances and integrate by
  fast-forward or stop for divergence review. Never force push.
- [ ] Verify local/remote main at the accepted final milestone commit.
- [ ] Check absence of `v0.4.0`, create the authorized annotated tag on integrated
  main and verify its peeled remote target after publication.
- [ ] Preserve all prior tag objects and targets.
- [ ] Remove only authorized branches proven integrated locally and remotely;
  retain any unmerged work.
- [ ] Leave main clean/synchronized and history/volumes intact, with final CI,
  reference, availability and evidence report.

Authentication, multiuser authorization, public hosting and a custom solver
are outside this checklist. VROOM stays behind `SolverGateway`.
